# AI Fluency Lab

Free tools by Nuhamin H. Tesfay to help people and teams use AI safely and well.

- `index.html`: home page
- `check.html`: AI Fluency Check (runs fully in the browser; no data is sent anywhere)
- `playbook.html`: AI Readiness Toolkit overview
- `toolkit/AI_Readiness_Toolkit.pdf`: downloadable 9-page toolkit

Free to use and share with credit.
